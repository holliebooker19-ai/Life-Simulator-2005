# 1998重生 · 人生模拟器

带着 2026 年的记忆，重生在 1998 年。用信息差赚钱、改写世界线。

```bash
npm install
npm run dev
```

规则与贡献方式见 [AGENT.md](./AGENT.md)。

## 部署（GitHub Pages）
1. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
2. 合并到 `main` 后自动构建并部署；也可在 Actions 页手动运行 “Deploy to GitHub Pages”。
3. 访问地址：`https://muxueliunian.github.io/Life-Simulator-2005/`
