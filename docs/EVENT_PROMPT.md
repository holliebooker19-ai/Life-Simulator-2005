# 事件批量生成提示词（给 Opus 5.5）

用法：把下面“提示词模板”整段发给模型，替换 `{{...}}` 占位。每次只生成一个主题批次（建议 15–25 个事件），
由模型在新分支上提交并开 PR。生成后人工抽查 `realFact`。

---

## 提示词模板

你在为网页游戏「1998重生」写事件内容。先完整阅读仓库根目录的 `AGENT.md`、`docs/NAMING.md`、`docs/EVENT_GUIDE.md`、`src/types.ts`，
再参考 `src/data/events/` 下现有文件的写法。

**设定**：主角 1998 年出生，带着 2026 年的现实记忆重生。玩家用“信息差”做决策（股市、世界杯、科技浪潮），
世界按真实历史走，只有主角**改写历史锚点**（`Effects.alter`）才会让世界线偏离；偏离越大记忆越不可靠。个人赚钱/成名不产生偏离。详见 `docs/EVENT_GUIDE.md` 的“世界线”。2026 年之后预知失效，进入自己经营世界线的阶段。
风格：写实为主，少量可被主角改变的荒谬剧情；简体中文；要“爽”，但要有代价和风险。

**本次任务**：为主题「{{主题，例如：2005–2012 年的青少年与家庭财富事件}}」新增 {{数量}} 个事件，
写入 `src/data/events/{{文件名}}.ts` 并在 `src/data/events/index.ts` 注册。

**必须遵守**
1. 所有真实人物、公司、产品按 `docs/NAMING.md` 改名；需要新改名时，先在该表追加条目（风格：谐音/反讽/一字之差）。政治人物允许调侃、恶搞，但同样只能用谐音/外号，不得出现真名，并遵守 `docs/NAMING.md` 的“政治调侃”边界。
2. 现实历史事件只写你确信的事实；拿不准的数字写模糊或不写。每个带 `year` 的事件必须填 `realFact`，写明事实与大致依据。
3. 年龄表：1998 出生 → 2005 年 7 岁，2008 年 10 岁，2010 年 12 岁，2013 年 15 岁，2017 年 19 岁，2020 年 22 岁，2022 年 24 岁，2026 年 28 岁。
   15 岁前的现实事件通过父母代理（`flags: ['family-has-money']` / `['parents-trust']`）参与，并用 `minAge` 约束。
4. 带选项的事件至少一个无条件选项；`usesMemory` 选项必须有 `success` 和 `misremember`（或 `fail`）结果。
5. 数值参考：`wealth` 单位万元；小赚 5–50，大赚 500–5000，首富级 100000+；改写锚点用 `alter: [{ id, scale }]`，小改动 scale 1~5，大改动 10~25（不要直接写 divergence，已移除）。
6. 世界线分岔用 `addFlags` 记录，并写至少 2 个依赖这些 flag 的后续事件（`flags` / `notFlags`）。
7. `legendary` 事件克制使用（每批不超过 3 个）；每批至少包含 3 个“没有现实对应的纯随机生活事件”，避免全是金融事件。

**自检（提交前必须全部通过并在 PR 里贴出结果）**
```bash
npm run typecheck && npm test && npm run build
```

**PR 描述需包含**：新增事件数量、新增改名条目、涉及的现实事实清单（事件 id → 事实 → 依据）、你不确定的地方。

---

## 推荐的主题批次顺序
1. 1998–2005：童年与家庭（含 1998、2002 世界杯、互联网泡沫等“父母代理”事件）
2. 2005–2012：少年、学业、家庭财富、智能手机崛起
3. 2013–2019：高中大学、创业、加密货币、短视频
4. 2020–2026：疫情、股市、AI 浪潮、2022 世界杯
5. 2026 之后：自己经营世界线（荒谬事件、首富、改写世界杯）
6. 结局扩充：见 `engine.ts` 的 `computeEnding`，需要时另开 PR
