# 路线图：世界线机制修正 + 2005 年之后的设计

> 状态：设计稿，尚未实现。实现前请先读 `AGENT.md`、`NAMING.md`、`EVENT_GUIDE.md`。
> 本文列出的现实事实仅为“锚点候选”，**写成事件前必须逐条核对**，拿不准的写模糊（AGENT.md 第 3 条）。

## 一、现状审计：世界线会不会和现实不一样？

目标原则：**世界按真实历史走；只有主角的个人影响才会让它偏离。**

### 现在的机制（读代码得出）
- 带 `year` 的现实事件**必定按年份触发**，不受玩家行为影响。所以“世界杯结果、股市走势”本身不会被改写——这一点符合原则。
- 但存在 4 处与原则不符的地方：
  1. **“个人下注”也会增加偏离度**。押对世界杯、清仓股票都给了 `divergence +1~3`（共约 20 处）。这些只是个人赚钱，并没有改变世界，却让“记忆可靠度”下降，等于惩罚玩家“世界没变却记不准”。
  2. **偏离度只是一个全局数字**，没有记录“具体改了哪件事”。所以无法做到“被改的那件事之后的历史跟着变、其他照旧”。
  3. **没有年份的随机事件会在任意年份触发**。如 `world-ai-lab`（写的是 2023 年的事）满足 18 岁 + 财富条件就可能在 2016 年出现；`absurd-richest-man` 同理。这会造出“和现实不一样、却不是玩家造成的”时间线。
  4. 新增的行动 `act-change-world`、`act-use-memory-fame` 只改数字，不改任何历史。

### 修正方案（设计）
1. **区分两种影响**
   - *个人层*：赚钱、成名、人脉。**不增加偏离度**，也不影响记忆可靠度。
   - *世界层*：玩家**明确改变了某个历史锚点**（让它没发生/结果不同）。只有这时才算偏离。
2. **锚点（Anchor）机制**：每个现实事件有稳定的 `id`，可被标记为“已被改写”。
   - `Effects.alter?: string[]`：写入 `state.altered`（被改写的锚点 id 集合）。
   - 锚点事件可写 `variants`：若 `altered` 里有它，则触发“改写后版本”，否则触发真实版本。
   - 锚点可写 `dependsOn: string[]`：依赖的锚点被改写时，它也随之改变或取消（蝴蝶效应）。
3. **偏离度改为由 `altered` 计算**：`divergence = Σ 被改锚点的 scale`（`scale` 按事件重要性 1~25）。
   记忆可靠度的惩罚只对**被改锚点及其下游**生效，不再全局扣。
4. **“能不能改”由影响力决定**：每个锚点有 `alterable?: { influence: number, ... }`。
   没达到门槛，选项里就只有“看着它发生”（或只能个人获利）。这样“世界大势不可动、有影响力才能动”。
5. **2026 年之后**：没有现实锚点，由玩家的 `altered`/flag 和随机事件决定世界走向。
6. **随机事件必须带 `minYear/maxYear`**（引擎已支持），带具体现实内容的随机事件一律改为锚点或限定年份。

### 需要的代码改动（工作量：小）
| 项 | 内容 |
| --- | --- |
| types/engine | `Effects.alter`、`GameState.altered`、`GameEvent.variants/dependsOn/scale`、`divergence` 改为派生值 |
| engine | `memoryReliability` 只扣下游偏离；`pickEvents` 处理 variants/dependsOn |
| 数据迁移 | 删除现有 ~20 处个人下注的 `divergence`；`world.ts` 两个事件限定年份 |
| 测试 | 个人下注不改偏离；改锚点后下游事件变化；随机事件必须有年份范围 |

## 三、2005 年之后的设计

### 现实锚点候选（需核对后才能写入 `realFact`）
> 标 ★ 表示适合做“可改写”的世界层事件；标 ⚠ 表示敏感或我对细节不够确定，需谨慎/核对后再写。

**2006–2010（7–12 岁，父母代理）**
- 2006：A 股大牛市启动；德国世界杯，意大利夺冠（决赛点球战胜法国）。
- 2007：A 股在 10 月前后见顶（约 6000 点以上）★（让家人提前离场）；第一代触屏智能手机发布（改名）。
- 2008：全球金融危机，大型投行倒闭；A 股大跌；北京奥运会；⚠ 汶川地震（不做搞笑，只做严肃/公益向）。
- 2009：国内出台大规模刺激、楼市回暖 ★（家庭买房时机）。
- 2010：世界杯（已有）、上海世博会；移动互联网起步。

**2011–2015（13–17 岁）**
- 2011：智能手机与社交软件普及；⚠ 日本大地震与核事故、高铁事故（严肃处理）。
- 2012：欧洲杯西班牙夺冠；伦敦奥运会。
- 2013：比特币首次站上 1000 美元★；互联网理财产品兴起。
- 2014：巴西世界杯，德国夺冠（半决赛 7:1 巴西）；大型电商公司海外上市（改名）。
- 2015：A 股年中见顶后暴跌★；汇率改革；移动支付、网约车、共享经济热。

**2016–2021（18–23 岁）**
- 2016：里约奥运；欧洲杯葡萄牙夺冠；英国公投脱欧、美国大选 ★⚠（政治，按 NAMING 调侃边界处理）。
- 2017：比特币年内暴涨至接近 2 万美元（已有）；短视频与手游热。
- 2018：俄罗斯世界杯，法国夺冠；中美贸易摩擦升级。
- 2019：年底新冠疫情初现 ⚠（涉及生命，写得克制）。
- 2020：疫情、美股多次熔断、全球宽松 ★（大放水前的买入机会）。
- 2021：比特币升至约 6 万美元以上、元宇宙概念、教培行业重大调整、芯片短缺。

**2022–2026（24–28 岁）**
- 2022：世界杯（已有）；俄乌冲突；年底对话式大模型发布（改名，已有 `closeai`/`ChatGPD`）。
- 2023：大模型热、算力概念爆发 ★（`world-ai-lab` 迁到此年份）。
- 2024：巴黎奥运；欧洲杯西班牙夺冠；比特币现货 ETF 获批、价格创新高。
- 2025–2026：**我对这两年的细节核对不充分**，写事件前由你提供事实清单或明确“只写大方向”。

### 2026 年之后（自由期）
- 现实记忆失效，`memoryReliability = 0`；预知选项不再出现，改为**判断型选项**（依赖智力、阅历、人脉）。
- 事件来源：玩家的 `altered` 世界线、公司/家庭/健康 flag 的后续、随机生活事件。
- 每 5 年一个“年代回顾”事件，按财富/影响力/改写数量给出世界新闻标题（让玩家看到自己造成的差异）。
- 结局扩充：首富、改写史书的人、隐居、桃李满天下、平凡幸福、早逝等 ~15 个，由 `altered` 数量与关键 flag 决定。

## 四、建议的实施顺序
1. **P0 世界线机制修正**（第一节，小改动 + 迁移）——先做，否则后面写的事件会继续沿用错误的偏离度。
2. **P1 童年阶段（2006–2012）**：约 20 个锚点 + 15 个生活事件。
3. **P2 少年/青年（2013–2021）**：约 25 个锚点、8 个可改写事件、20 个生活事件。
4. **P3 成年（2022–2026）与可改写高潮**：约 15 个锚点、7 个可改写。
5. **P4 自由期（2027+）与结局扩充**：约 40 个事件 + 10 个结局。
6. 每批后：数值试玩平衡（行动收益、财富曲线），补测试，`npm run typecheck && npm test && npm run build`。
